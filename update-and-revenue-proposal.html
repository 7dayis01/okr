3 익스 KR1 [통합 매출] — 측정 방법 제안 제안

⚠️ 현재 값이 두 방식이 섞여 있습니다 — 시작 100 / 현재 31 / 목표 110 → 계산이 꼬여 진척률 0%(위험)로 잘못 표시됩니다.
구분측정 방법값 설정장점
추천 A
사업 KR		1~N월 누적매출 ÷ 전년 같은 기간(1~N월) × 100시작 100 · 목표 110 · 단위 %
현재값 = 매달 계산값		연중 언제 봐도 "전년 대비 몇 %"가 의미 있음
참고 B
대안		금액으로 직접 입력 (누적 매출액)시작 0 · 목표 전년총액×1.1
단위 억원		"얼마 벌었나"가 직관적. 단 연중엔 %가 낮게 보임(정상)
추천 C
하위 과제		KR이 "개인+기업"이므로 하위 과제 2개로 분리
① 개인 매출 ② 기업 매출		각각 금액으로 관리
시작 0 · 목표 = 각 목표액		어디서 매출이 나오는지 세부 추적 가능
왜 A인가 (핵심)
지금처럼 전년 "총매출"과 비교하면, 5월 시점엔 자연히 30% 수준이라 "위험"처럼 보이지만 실제론 정상일 수 있습니다.
전년 "동기간"과 비교해야 "전년 대비 110% 달성" 목표가 연중 내내 올바르게 측정됩니다.
매달 운영 방법
① 매달 (1~N월 누적매출 ÷ 전년 1~N월) × 100 을 계산해 현재값에 입력
② 체크인 메모에 근거를 기록 (예: "1~5월 누적 33억 / 전년 동기 31억")
③ 자동으로 추세 그래프가 쌓여 매출 성장 곡선을 볼 수 있음
