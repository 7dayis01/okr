· 로그인 비밀번호는 전원 1234 입니다. 다른 분 계정으로 들어가 권한 차이도 확인해보실 수 있습니다.
· 화면 왼쪽 아래 보라색 TEST 표시가 있으면 테스트 환경입니다.

1하위 업무 — 실무를 표로 관리신규

KR은 "수수료 15% 인상" 같은 목표입니다. 그 목표를 이루려고 실제로 하는 일(어떤 광고주와 언제 무엇을 협의하는지)을 KR 아래에 표로 붙였습니다. KR마다 다른 표를 만들 수 있습니다.

1
사업별 탭에서 KR 오른쪽의 파란 업무 1/4 배지를 클릭합니다. (또는 KR을 열어 업무 관리 열기 버튼)
2
+ 업무 추가 — 줄이 하나 생깁니다. 업무 내용·담당·기한·상태(대기/진행/완료)·비고를 입력합니다.
3
+ 열 추가 — 필요한 항목을 직접 만듭니다. 예: 광고주명 월 집행액 계약일. 숫자 열인지 텍스트 열인지 선택합니다.
4
저장 버튼이 없습니다. 칸을 벗어나면 즉시 저장되고, 같은 화면을 보고 있는 다른 사람에게도 바로 반영됩니다.

이렇게 쓰시면 됩니다

  • KR「수수료 15% 인상」 → 업무 = 광고주별 협의 건
  • KR「3PL 5개사 계약」 → 업무 = 후보사별 진행 상황
  • KR「채널 11개 풀가동」 → 업무 = 플랫폼별 입점 상태

누가 편집할 수 있나

  • KR 목표값·현재값 — 관리자만 (기존 그대로)
  • 하위 업무 — 관리자 + 담당자 + 그룹 리더
  • 담당이 아닌 분은 조회만 됩니다
왜 담당자에게 열었나 — 실무 내용은 담당자가 가장 잘 알고 매일 바뀝니다. 관리자만 고칠 수 있으면 표가 금세 낡습니다. 대신 목표 숫자는 여전히 관리자만 바꿀 수 있어, 목표가 임의로 흔들리지는 않습니다.
지금은 참고용입니다 — 업무 표의 내용이 KR 진척률에 자동 반영되지는 않습니다. 먼저 써보시고, "완료 개수 비율" 또는 "숫자 열 합계"를 진척률에 연결할지 나중에 정하겠습니다.
2마감일 · 일정 탭신규

기존 실행 기간 칸은 자유 텍스트라 컴퓨터가 못 읽었습니다. 시작일 / 마감일을 날짜로 받는 칸을 추가해, 남은 날짜와 지연을 자동으로 계산합니다.

1
KR을 클릭해 열면 시작일 · 마감일 칸이 있습니다. 날짜를 고르고 저장합니다.
2
저장하면 KR 옆에 자동으로 배지가 붙습니다 — D-54 D-2 지연 7일 정체 기한 미설정
3
일정 탭에서 분기 타임라인을 봅니다. 막대는 시작일~마감일이고, 빨간 세로선이 오늘입니다. ◀ 이전 다음 ▶ 로 분기를 옮깁니다.
구분판정 기준 (자동)어떻게 보이나
지연마감일이 지났는데 100%가 아님빨간 막대 / '내 업무' 맨 위
이번 주 마감마감일이 7일 이내주황 막대 / D-일수 표시
정체마감 전이지만 14일 이상 값·메모·업무 변화 없음보라 막대
기한 미설정마감일을 아직 안 넣음목록 맨 아래에 따로 모임
날짜를 꼭 넣어야 하나요? 강제는 아닙니다. 다만 날짜가 없으면 지연·정체 판정과 타임라인에서 빠지고 기한 미설정으로만 모입니다. 담당 KR부터 하나씩 채워주시면 됩니다.

활동 탭 — 전사 변경 이력

누가 무엇을 언제 바꿨는지 시간순으로 쌓입니다.

  • 현재값 변경 (0 → 82)
  • 마감일 변경
  • 확신도 변경
  • 코멘트 작성 · @언급

전체 / 내 관련 로 걸러 볼 수 있고, 마지막 접속 이후 새 소식은 탭에 빨간 숫자로 표시됩니다.

코멘트 · @언급

KR을 열면 아래에 코멘트 영역이 있습니다.

  • 메모 한 칸을 덮어쓰지 않고 대화가 쌓입니다
  • @박근정 처럼 이름을 부르면 그분 활동 탭에 표시됩니다
  • "왜 멈춰 있었는지"가 기록으로 남습니다

확신도 신호등

KR 안에서 담당자가 순조 / 주의 / 위험을 직접 고릅니다. 숫자는 좋아 보여도 담당자만 아는 위험이 있기 때문입니다. 잠금 중에도 담당자가 바꿀 수 있습니다.

대시보드 추가 지표

  • 이번 주 체크인 현황 — 최근 7일간 몇 명이 업데이트했는지
  • 담당자별 KR 부하 — 누가 몇 건을 지고 있는지, 지연은 몇 건인지
알림의 한계 — 미리 말씀드립니다
앱에 들어왔을 때 빨간 배지로 알려주는 것까지가 가능합니다. 앱이 꺼져 있는데 카톡·이메일·휴대폰 푸시를 보내는 것은 지원되지 않습니다(별도 서버와 유료 전환이 필요). 그래서 알림보다 주 1회 업데이트 습관이 훨씬 중요합니다.
